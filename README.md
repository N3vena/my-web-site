How to Run the Website:
To launch the website, open the project folder and locate the index.html file. Simply double-click index.html to open it in your web browser.
Make sure all other HTML files (novosti.html, galerija.html, likovi.html, kontakt.html) remain in the same root folder so the navigation functions correctly. All images are stored in the images folder and must stay in that directory for them to display properly.
